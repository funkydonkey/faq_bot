How It Works

📚

1. Upload Documents

Drop your DOCX, DOC, or TXT files into the docs/ folder. The system indexes them using LangChain's text splitter (500 char chunks, 200 overlap) and creates embeddings with OpenAI's text-embedding-3-small.

❓

2. Ask Questions

Type your question in natural language. The OpenAI Orchestrator (GPT-4o) receives it and decides whether to clarify entities first or search directly.

🔍

3. Smart Processing

The Clarification Agent extracts key entities using hybrid search (LLM + vector fallback). Then the AutoGen Search Agent retrieves relevant chunks from your documents.

✅

4. Get Answers

GPT-4o synthesizes the information and gives you a clear answer. All conversations are stored in SQLite, so the bot remembers context across sessions.

Understanding Document Indexing

Before the bot can answer questions, your documents need to be indexed. Here's what happens behind the scenes:

1

Document Processing

Your documents (DOCX, DOC, or TXT) are read and parsed. The system extracts all text content, including paragraphs and tables, while removing formatting. Long documents are automatically split into smaller chunks (500 characters each with 200-character overlap) to ensure context isn't lost between sections.

Input: HR_Policy.docx (2MB, 50 pages)
Output: ~250 text chunks ready for processing
Example chunk: "Vacation policy: Full-time employees receive 15 days of paid vacation per year..."
Technical: Uses python-docx for Word files and RecursiveCharacterTextSplitter from LangChain to intelligently split text at paragraph and sentence boundaries.
2

Vector Embeddings

Each text chunk is converted into a mathematical representation called a "vector embedding" - essentially a list of 1,536 numbers that captures the semantic meaning of the text. OpenAI's text-embedding-3-small model generates these embeddings.

Text chunk: "vacation policy for employees"
Embedding: [0.23, -0.45, 0.12, 0.67, -0.89, ...] (1,536 numbers total)
Why embeddings? Computers can't understand text directly, but they can compare numbers. Similar concepts get similar vector values, so the bot can find "time off" even if you search for "vacation". This is how semantic search works - it understands meaning, not just keywords.
Cost: At $0.02 per 1M tokens, embedding a 2MB document costs ~$0.0025. Super cheap!
3

Knowledge Graph Construction

Here's where the magic happens: GPT-4o-mini analyzes each chunk and extracts entities (people, departments, policies, dates) and their relationships. This creates a structured knowledge graph that connects related information across your entire document collection.

HR Department
→ manages →
Vacation Policy
Vacation Policy
→ grants →
15 Days Annually
15 Days Annually
→ applies to →
Full-time Employees
Why a knowledge graph? When you ask "How much vacation do full-time employees get?", the bot can traverse the graph: Full-time Employees → 15 Days → Vacation Policy, connecting the dots even if these facts appear in different parts of the document.
Storage: The knowledge graph, embeddings, and all indexed data are stored locally in the kb/ directory as JSON files. You can back it up, version control it, or delete and rebuild it anytime.

Features

⚡

Fast Setup

Clone the repo, install dependencies, add your API key, and you're ready to go. Takes about 5 minutes.

🔒

Local First

Your documents stay on your machine. Only questions and answers are sent to OpenAI's API for processing.

💰

Cost Efficient

Uses gpt-4o-mini for indexing ($0.11 per document) and gpt-4o for queries ($0.02 per question). Much cheaper than enterprise solutions.

🎨

Clean UI

Simple Gradio interface for chat (port 8080) and a separate admin interface for document management (port 8081).

🔍

Hybrid Search

Combines LLM-based entity extraction with direct vector search fallback for maximum accuracy and recall.

📝

Multiple Formats

Supports DOCX, DOC, and TXT files out of the box. PDF and Excel support planned for future releases.

Basic usage example 
from openai_agent import OpenAIAgentRunner

# Initialize with your document
agent = OpenAIAgentRunner(docx_path="docs/policy.docx")

# Ask a question
answer = agent.process_query("What is our vacation policy?")
print(answer)

Cost Optimization

The system uses gpt-4o-mini for indexing (94% cheaper than gpt-4o) and gpt-4o for runtime queries. Embeddings use text-embedding-3-small (6.5x cheaper than large). See MODEL_OPTIMIZATION.md for full cost breakdown.
