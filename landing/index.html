Getting Started

1

Install

git clone https://github.com/funkydonkey/faq_bot cd faq_bot python3.12 -m venv venv source venv/bin/activate pip install -r requirements.txt
2

Configure

echo "OPENAI_API_KEY=your-key" > .env mkdir docs cp your-document.docx docs/ python indexing.py
3

Run

python app.py # Open http://localhost:8080 # Start asking questions!

Requirements: Python 3.12, OpenAI API key

Supported formats: DOCX, DOC, TXT (PDF and Excel coming soon)

📚 Document Processing

Documents are split into chunks using LangChain's RecursiveCharacterTextSplitter (500 chars, 200 overlap). Each chunk is embedded using OpenAI's text-embedding-3-small and stored in a MiniRAG knowledge graph.

🤖 Three-Layer Agents

The system uses an OpenAI Agents SDK orchestrator that coordinates a clarification agent (for entity extraction) and an AutoGen search agent (for document retrieval). This architecture handles ambiguous queries intelligently.

💾 Conversation History

All conversations are stored in SQLite, so the bot remembers context across sessions. You can clear history anytime from the chat interface.

Features

⚡

Fast Setup

Clone the repo, install dependencies, add your API key, and you're ready to go. Takes about 5 minutes.

🔒

Local First

Your documents stay on your machine. Only questions and answers are sent to OpenAI's API for processing.

💰

Cost Efficient

Uses gpt-4o-mini for indexing ($0.11 per document) and gpt-4o for queries ($0.02 per question). Much cheaper than enterprise solutions.

🎨

Clean UI

Simple Gradio interface for chat (port 8080) and a separate admin interface for document management (port 8081).

🔍

Hybrid Search

Combines LLM-based entity extraction with direct vector search fallback for maximum accuracy and recall.

📝

Multiple Formats

Supports DOCX, DOC, and TXT files out of the box. PDF and Excel support planned for future releases.

Basic usage example 
from openai_agent import OpenAIAgentRunner

# Initialize with your document
agent = OpenAIAgentRunner(docx_path="docs/policy.docx")

# Ask a question
answer = agent.process_query("What is our vacation policy?")
print(answer)

Cost Optimization

The system uses gpt-4o-mini for indexing (94% cheaper than gpt-4o) and gpt-4o for runtime queries. Embeddings use text-embedding-3-small (6.5x cheaper than large). See MODEL_OPTIMIZATION.md for full cost breakdown.
