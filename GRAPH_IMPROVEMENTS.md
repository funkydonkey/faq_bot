## 🚀 Как использовать

### Запуск приложения

```bash
# Из корневой директории проекта
streamlit run "pages/2_🕸️_Knowledge_Graph.py" --server.port 8083

# Или используйте run_streamlit.py для запуска основного приложения
```

Доступ: http://localhost:8083

### Основные функции

1. **Фильтрация узлов:**
   - Используйте слайдер "Максимум узлов" для ограничения количества
   - Выберите типы узлов через чекбоксы
   - Установите минимальное количество связей
   - Введите поисковый запрос для поиска по названию

2. **Режимы отображения:**
   - **Сетевой** - естественное расположение узлов (по умолчанию)
   - **Иерархический** - древовидная структура

3. **Интерактивность:**
   - Кликните на узел для просмотра деталей
   - Перетаскивайте узлы для изменения расположения
   - Наведите курсор на узел/связь для tooltip
   - Используйте колесико мыши для zoom

## 🔧 Технические детали

### Алгоритм forceAtlas2Based

```python
physics={
    'enabled': True,
    'solver': 'forceAtlas2Based',
    'forceAtlas2Based': {
        'gravitationalConstant': -50,      # Отталкивание узлов
        'centralGravity': 0.01,             # Слабое притяжение к центру
        'springLength': 200,                # Настраиваемое расстояние
        'springConstant': 0.08,             # Жёсткость связей
        'damping': 0.4,                     # Замедление для стабилизации
        'avoidOverlap': 1                   # Предотвращение наложения
    },
    'stabilization': {
        'enabled': True,
        'iterations': 1000,
        'updateInterval': 25
    }
}
```

### Фильтрация узлов

Узлы фильтруются в порядке:
1. По типам сущностей (selected_types)
2. По минимальному количеству связей (min_connections)
3. По поисковому запросу (search_query)
4. Сортировка по количеству связей (desc)
5. Ограничение до max_nodes

### Динамический размер узлов

```python
node_size = min(15 + connections * 2, 40)
```

- Минимум: 15 (узлы с малым количеством связей)
- Максимум: 40 (узлы-хабы с большим количеством связей)
- Масштабирование: +2 за каждую связь

## 🐛 Известные ограничения

1. **Экспорт в PNG** - не реализован в интерактивном режиме
   - **Workaround:** Используйте `scripts/graph.py` для статического PNG

2. **Кластеризация** - не реализована
   - **Workaround:** Используйте фильтры по типам + минимальное количество связей

3. **Zoom на узел** - ограничение streamlit-agraph
   - **Workaround:** Используйте поиск + фильтры

4. **Session state при перезагрузке** - не сохраняется
   - **Workaround:** Фильтры сохраняются во время сеанса

## 💡 Рекомендации по использованию

### Для первого знакомства
1. Начните с 20-30 узлов
2. Выберите 1-2 типа узлов (например, CONCEPT + EVENT)
3. Установите мин. связей = 2

### Для поиска ключевых концепций
1. Увеличьте мин. связей до 5-10
2. Используйте сетевой режим
3. Узлы-хабы будут самыми большими

### Для изучения иерархии
1. Выберите иерархический режим
2. Ограничьте количество узлов до 30-40
3. Фильтруйте по конкретным типам

### Для поиска конкретной информации
1. Используйте поиск по ключевому слову
2. Кликните на найденный узел
3. Изучите связанные узлы в таблице
